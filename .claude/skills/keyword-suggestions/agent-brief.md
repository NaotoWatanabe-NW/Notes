読書記録アプリの「キーワードのおすすめ」を選ぶ作業です。指示どおりに進めてください。

## 入力
- 対象: {BATCH} を Read する
  - `keyword`: キーワード。このキーワードについて読む本を選ぶ
  - `genre`: ジャンルの指定（null なら自分で決める）
  - `related`: キーワードの文字列一致で拾った本棚の本の id。**取りこぼしも誤りもある出発点**
  - `slots`: 区分ごとの冊数。`need`: 距離ごとにあと何冊要るか。`existing`: すでに設定してある候補
- 本棚: {SHELF} を Read する。持ち主がすでに持っている本（id・書名・著者・タグ・状態・評価・メモ）。**ここにある本は候補にしない**（同じ本の別版・文庫版・上下巻の片方も含めて出さない）

## 1. 手がかりにする本を決める
- 本棚から、キーワードに関係する本を選ぶ。`related` から始め、書名に語が出てこなくても内容が関係する本は足し、関係しない本は外す。0冊でもよい
- 手がかりの本ごとに、難しさ（入門書 / 一般書・新書 / 専門書）と、持ち主の読み具合（`status`・`rating`・`notes`）をつかむ。読了・評価の高い本・メモのある本を重く見る

## 2. ジャンルを決める
`genre` が指定されていればそれに従う。null なら、キーワードと手がかりの本から1つ選ぶ。迷ったら study。

- `study`: 勉強系・教養書・実用書
- `novel`: 小説
- `essay`: エッセイ
- `selfhelp`: 自己啓発

## 3. 区分ごとに選ぶ
区分は `same` / `adjacent` / `side` の3つ。中身はジャンルで変わる。

| 区分 | study | novel（仮） | essay（仮） | selfhelp（仮） |
|---|---|---|---|---|
| same | **同じテーマの難易度別**。手がかりの本より一段やさしい本と、一段深い本。手がかりが入門書ばかりなら、同じくらいの別の切り口の本と一段深い本。手がかりが無ければ入門書とその次に読む本 | 同じ作家の別の作品（代表作から） | 同じ書き手の別の本 | 主張の元になった研究・学術寄りの本 |
| adjacent | **近いテーマ**。隣の分野で、キーワードの理解が深まる本 | 読後感やテーマが近い、別の作家の作品 | 同じ題材を扱う、別の書き手の本 | 実践の本（手順・ワークブック） |
| side | **少し離れた、かんたんに読める本**。分野は違うが関心がつながる新書・図解・読み物 | 小説が扱う題材のノンフィクション | 題材を学べるやさしい入門書 | 反対・批判の立場の本 |

（仮）の列はまだ試している途中のルール。選びにくかった・合わないと感じたら、返答でそう報告する。

冊数:
- `existing` が空なら、`slots` の数どおりに選ぶ
- `existing` があるとき（補充）は、`need` の `near`（= same と adjacent の合計）と `far`（= side）を満たす数だけ選ぶ。`existing` の理由から区分を見分け、足りない区分を補う。**同じ本を選ばない**

## 選び方（共通）
- 日本語で読める本（和書・翻訳書）。いま入手できる版を選ぶ
- **シリーズものは1作目か、単独で読める巻を選ぶ**（途中の巻は選ばない）
- 上下巻に分かれる本は **上巻** の ISBN を使う
- 同じ本を2つの区分に重ねない
- `from_book_id`: その候補の手がかりにした本棚の本の id（整数）。`same` は手がかりの本があれば必ず入れる。ほかの区分も特定の本から選んだなら入れる。無ければ null
- `category`: 候補の本のカテゴリを **小説 / ビジネス・実用 / エッセイ / 学術 / 雑誌 / その他** から1つ、この表記のまま書く（教養書・新書・専門書・入門書は 学術、思考法・仕事術・自己啓発・技術書・実用書は ビジネス・実用、随筆は エッセイ）。おすすめ一覧のカテゴリの絞り込みに使う
- `reason`: **です・ます調、60字以内の一言**。**手がかりの本との関係と、難しさの違い**が分かるように書く
  - 例:「『ゲーム理論の思考法』より数式が多く、理論を一段深く押さえられます。」
  - 例:「『プログラマの数学』の前に読むと、確率の土台がやさしく固まります。」
  - あらすじや宣伝文句の丸写しにしない

## 実在確認（必須）
- 候補ごとに WebSearch / WebFetch で**実在を確かめ、ISBN-13 を取る**。出典は 版元ドットコム(hanmoto.com)・出版社の公式ページ・国立国会図書館サーチ を優先する。直接開けなければ、検索結果に出る書名・著者・ISBN を複数の出典で突き合わせる
- **ISBN を推測や記憶で書かない**。確かめられなかった本は候補から外し、別の本を選んで確かめ直す
- 品切れ・絶版と分かった本は避ける
- `title` は書名のみ（「(講談社現代新書)」のようなレーベル名の括弧は付けない。副題は付けてよい）。`author` は著者のみ（訳者は入れない）。外国人の著者はカナで書く
- `source` には ISBN を確かめたページの URL を入れる

## 出力
{OUT} に Write する。形式は次のとおり（JSON オブジェクト1つ、この形以外にしない）:

```json
{"keyword": "キーワード", "genre": "study", "related_books": [25, 31],
 "suggestions": [
  {"title": "書名", "author": "著者", "isbn": "978XXXXXXXXXX", "slot": "same",
   "from_book_id": 25, "category": "学術", "reason": "一言の理由", "source": "https://..."}
 ]}
```

- `keyword` は対象のキーワードをそのまま書く
- `related_books` は 1 で選んだ手がかりの本の id

## 返答
選んだジャンルとその理由、手がかりにした本、確かめられずに差し替えた本、判断に迷った点（特に仮ルールのジャンル）を短く報告する。JSON の中身は返答に貼らない。
