読書記録アプリの「次に読む本」の候補を選ぶ作業です。指示どおりに進めてください。

## 入力
- 対象の本: {BATCH} を Read する
- 除外リスト: {SHELF} を Read する。持ち主の本棚にすでにある本。**ここにある本は候補にしない**（同じ本の別版・文庫版・上下巻の片方も含めて出さない）

## 選ぶ数
- 対象の本ごとに、`need` に書かれた数だけ選ぶ。`{"near": 2, "far": 1}` なら near を2冊、far を1冊
- `existing` はその本にすでに設定してある候補。**同じ本を選ばない**。足りない分を補う立場なので、既存の候補と毛色がかぶらない本を選ぶ
  - near: 同じテーマを、もう一段深く、または別の角度から扱う本
  - far: 分野は違うが、この本を読んだ人の関心が自然につながる本（例: 言語人類学 → 認知科学、科学史 → イノベーション論）

## 選び方
- 日本語で読める本（和書・翻訳書）。いま入手できる版を選ぶ。一般書・新書・選書・文庫を優先し、元の本が入門書なら専門書は避ける
- **シリーズものは1作目か、単独で読める巻を選ぶ**（「〇〇ごはん8」のような途中の巻は選ばない）
- 上下巻に分かれる本は **上巻** の ISBN を使う
- 同じ対象の本の中で、同じ本を重複させない
- `basis`:
  - 対象の本に `notes`（引用・メモ）があれば、その中身に触れた候補は "note"。`reason` にもメモのどこにつながるかを書く
  - `rating` があって、評価の高さ・低さを手がかりにした候補は "rating"
  - どちらでもなければ "tag"（分野から）
- `category`: 候補の本のカテゴリを **小説 / ビジネス・実用 / エッセイ / 学術 / 雑誌 / その他** から1つ、この表記のまま書く（教養書・新書・専門書・入門書は 学術、思考法・仕事術・自己啓発・技術書・実用書は ビジネス・実用、随筆は エッセイ）。おすすめ一覧のカテゴリの絞り込みに使う
- `reason`: **です・ます調、60字以内の一言**。元の本とのつながりが分かるように書く（例:「ピダハンの『数のない言語』から、数量認知という認知科学の問いへとつながります。」）。あらすじや宣伝文句の丸写しにしない

## 実在確認（必須）
- 候補ごとに WebSearch / WebFetch で**実在を確かめ、ISBN-13 を取る**。出典は 版元ドットコム(hanmoto.com)・出版社の公式ページ・国立国会図書館サーチ を優先する。直接開けなければ、検索結果に出る書名・著者・ISBN を複数の出典で突き合わせる
- **ISBN を推測や記憶で書かない**。確かめられなかった本は候補から外し、別の本を選んで確かめ直す
- 品切れ・絶版と分かった本は避ける
- `title` は書名のみ（「(講談社現代新書)」のようなレーベル名の括弧は付けない。副題は付けてよい）。`author` は著者のみ（訳者は入れない）。外国人の著者はカナで書く
- `source` には ISBN を確かめたページの URL を入れる

## 出力
{OUT} に Write する。形式は次のとおり（JSON 配列、この形以外にしない）:

```json
[
  {"book_id": 19, "suggestions": [
    {"title": "書名", "author": "著者", "isbn": "978XXXXXXXXXX", "basis": "tag", "distance": "near", "category": "学術", "reason": "一言の理由", "source": "https://..."}
  ]}
]
```

対象の本すべてについて1要素ずつ出す。

## 返答
処理した冊数、確かめられずに差し替えた本があればその書名、判断に迷った点を短く報告する。JSON の中身は返答に貼らない。
